# SnapDrop

<!-- impeccable:product-schema 1 -->

## Platform

Native Windows desktop application, Windows 11 x64 first.

## Stack

User-approved C#/.NET 10 and WPF, Win32 clipboard notifications, Windows OLE file drag, native file dialogs, local filesystem storage.

## Users and purpose

People who repeatedly capture screenshots and attach or organize them. Capture with Win + Shift + S, then drag a floating thumbnail into a supported destination, copy the image, or choose Save As.

## Constraints

The approved Implementation.md and docs/UX_SPEC.md establish scope and interaction design. Companion mode monitors all supported new clipboard images only after opt-in. No cloud backend, telemetry, native capture, OCR, annotation, recording, or AI in v0.1. Images have independent UI and storage lifetimes.

## Visual commitments

The user explicitly approved the existing Windows-native brief and instructed implementation without routine reconfirmation. Inherit its compact thumbnail, standard typography/system colors, restrained surfaces, accessible native controls, and non-activating arrival. No replacement visual-world exploration is needed.

## Evidence

Blueprint exists. Source implementation is in progress; live verification remains subject to Context.md.
